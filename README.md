# SimpleSchedule

**Team:** Bits, Bytes, & Compilers. Ryan, Benjamen, Aboubacar.

SimpleSchedule is a small web app for booking meetings. A host sets the days and
times they are available, shares a public booking link, and guests pick an open
time without needing an account. It is built for students, tutors and small
teams who want scheduling without a complicated tool.

## Technologies used

- HTML
- CSS
- JavaScript
- Node.js
- MongoDB (Atlas)
- Git and GitHub
